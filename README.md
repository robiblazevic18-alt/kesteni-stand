# Štand – kesteni, kukuruz, kokice i igračke

Web aplikacija (PWA) koja se instalira na mobitel. Podaci su u Supabase projektu `kesteni-stand`.

- **Radnik**: samo primopredaja smjene.
- **Admin**: primopredaja, igračke, nabava, zaliha, artikli i cijene, izvještaji, radnici.

Objava: sadržaj ove mape staviti na bilo koji statički hosting (GitHub Pages, Netlify…).
